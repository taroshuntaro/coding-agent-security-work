# 07 共通の推奨コマンドポリシー

[← 目次へ戻る](README.md)

プロジェクトごとに実際のコマンドを棚卸しし、次のように分類する。

## 7.1 自動許可の候補

- `git status`
- `git diff`
- `git log`
- プロジェクト内の検索
- Lint
- 単体テスト
- 型チェック
- ローカルビルド
- フォーマット
- 読み取り専用のコード生成確認

自動許可する場合も、コマンドが任意スクリプトを間接実行しないか確認する。たとえば `npm test` の実体はリポジトリ内の任意スクリプトである。

## 7.2 都度確認の候補

- 新しい依存パッケージの追加・更新（名前の実在と提供元を確認する。[7.4](#74-依存パッケージの追加)）
- `npm install`、`pip install`、Maven/Gradleの依存変更
- DBマイグレーション生成
- Dockerイメージのビルド
- `git commit`
- PR・Issueの作成
- 外部URLへのアクセス
- コード生成ツールの初回実行

## 7.3 原則拒否の候補

- `git push --force`
- `git reset --hard` を共有ブランチへ適用する操作
- `curl`、`wget` による任意送信
- `ssh`、`scp`
- `kubectl`、`helm` の変更操作
- `terraform apply`、`destroy`
- `aws`、`az`、`gcloud` の変更操作
- 本番DBクライアント
- デプロイコマンド
- パッケージレジストリへの公開（`npm publish`、`gradle publish`、`twine upload` 等）
- シークレットの表示
- Dockerソケット経由のホスト操作
- 権限昇格、`sudo`
- ワークスペース外への削除・書き込み

拒否対象はコマンド名だけでなく、MCP、Hooks、スクリプト、CI/CD経由の同等操作も含める。

> [!WARNING]
> コマンド文字列のallow/denyパターンだけを、強いセキュリティ境界として扱わない。ラッパースクリプト、別名コマンド、シェル展開、インタプリタ経由、MCP、ビルドツール経由で同じ副作用を起こせる。
> 強い制御が必要な操作は、ファイルシステム、ネットワーク、資格情報、外部サービス側RBAC、コンテナ・VMで到達不能にする。

## 7.4 依存パッケージの追加

依存パッケージの追加は、エージェントが提案し、エージェントが実行できる操作である。人間が名前を確認しないまま進むと、次の攻撃に直接さらされる。

- **存在しないパッケージ名の提案（slopsquatting）**: LLMは実在しないパッケージ名をもっともらしく提案することがあり、同じ名前が繰り返し提案される傾向がある。攻撃者はその名前で悪性パッケージを先に公開しておける（[20](20-references.md)の USENIX Security 2025 論文）。
- **正規パッケージの乗っ取り**: 正規のパッケージに悪性の版が公開され、インストールスクリプトが実行される。多くは公開から数時間〜1日程度で検知・削除されている。

推奨:

- 新しい依存の追加は都度確認にし（7.2）、パッケージ名の実在・提供元・利用実績を人間が確認する。
- 社内ミラー・許可済みレジストリ経由で取得し、lockfileとハッシュで固定する。CIでは lockfile どおりにインストールする（`npm ci` 等）。
- 公開から一定期間が経過した版だけを取得する設定（クールダウン）を使う。緊急の脆弱性修正は、例外リストで個別に許可する。
- インストールスクリプトの実行を既定で止め、必要なパッケージだけ許可する（npm の `--ignore-scripts` 等。パッケージマネージャーごとの既定を確認する）。

| パッケージマネージャー | クールダウン設定 | 単位 | 既定 | 導入版 |
|---|---|---|---|---|
| npm | `min-release-age`（除外: `min-release-age-exclude`） | 日 | なし | CLI 11.10.0（除外は 11.17.0） |
| pnpm | `minimumReleaseAge`（除外: `minimumReleaseAgeExclude`） | 分 | v11以降 1440（v10は0）。既定値は非strictで、古い版へフォールバックする | 10.16.0 |
| Yarn (Berry) | `npmMinimalAgeGate`（除外: `npmPreapprovedPackages`） | 分（または `1d` 等） | 4.15.0以降 `1d` | 4.10.0 |
| Bun | `install.minimumReleaseAge`（除外: `minimumReleaseAgeExcludes`） | 秒 | なし | 1.3 |
| uv | `exclude-newer`（相対指定 `"7 days"` 等） | 期間または日時 | なし | 相対指定は 0.9.17 |
| pip | `--uploaded-prior-to`（`PIP_UPLOADED_PRIOR_TO`） | 日時または `P3D` 等 | なし | 26.0（期間指定は 26.1） |

> [!NOTE]
> 上表は2026-09-23に各公式ドキュメントで確認した。設定名・既定値は変わり得るため、導入時に対象バージョンで確認する。
